資料後台
回網站

使用方式：編輯資料後按右上角「儲存到 GitHub」，會直接寫回 repo，網站一到兩分鐘後自動更新。

第一次使用請先按「設定」填入存取權杖（Token）。若不想設定，也可以按「下載 JSON」後手動上傳到 GitHub。

GitHub 連線設定

權杖存在這台電腦的瀏覽器裡，不會傳給任何第三方，只會用來呼叫 GitHub API。共用電腦請勿儲存。
取得方式：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 選這個 repo → Repository permissions 的 Contents 設為 Read and write。
